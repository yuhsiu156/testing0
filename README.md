# 台股五條件突破監控（雲端版）

第一版可追蹤最多 20 檔台灣上市／上櫃股票，分析 **底部整理、量縮價穩、帶量突破、均線趨勢、避免追高**，顯示「符合突破／接近突破／整理中／不符合」。提供價格與均線圖、成交量圖、可調整參數、CSV 下載及 GitHub Actions 固定清單盤後排程。

## 部署（Streamlit Community Cloud）

1. 建立 GitHub repository，將本專案的**所有檔案與資料夾**上傳，包含 `.github/workflows/daily.yml`。
2. 到 https://share.streamlit.io/ 登入 GitHub，選「Create app」並選擇 repository，主程式 `app.py`，按 Deploy。
3. 進入網站，在左欄輸入要追蹤的代碼（最多20檔）。建議上市代碼如 `2330.TW`；上櫃代碼如 `6488.TWO`。不加後綴時會先嘗試 `.TW`，再嘗試 `.TWO`。
4. **要長期固定自動追蹤**，在 GitHub repository 修改 `watchlist.txt`（每行一檔），並提交變更。網站輸入框的變更**不會**自動寫回 GitHub，也**不會**成為隔日排程名單。
5. GitHub → Actions → Daily TW stock analysis → Run workflow，可手動啟動一次測試。排程為台灣時間週一到週五 16:30，GitHub 排程可能延誤，遇國定假日會使用最近可得的交易日資料。
6. 批次結果存於 `data/latest.csv`，歷史訊號存於 `data/history.csv`。**目前網站畫面會直接抓行情重新計算**，`data/*.csv` 是備份、歷史紀錄與日後擴充通知功能使用，並非畫面資料庫。

## 本機測試

```bash
python -m pip install -r requirements.txt
streamlit run app.py
# 如要產生排程快照：
python update_daily.py
```

## 條件（預設）

- 底部整理：**不含今日**前30日最高/最低價幅度 ≤ 20%。這是整理區間代理，不保證為底部。
- 量縮價穩：**不含今日**前10日均量 ≤ 更早20日均量的85%；前10日高低幅度 < 前30日高低幅度。
- 帶量突破：今日收盤 > 前30日最高價；今日成交量 ≥ **不含今日**前20日均量的1.5倍。
- 均線趨勢：今日收盤 > 今日20、60日均線，今日20日均線 > 五個交易日前的20日均線。
- 避免追高：今日收盤突破前30日最高價，且高出幅度 ≤ 5%。
- 接近突破：底部整理、量縮價穩、均線趨勢都通過；距突破價為 -3% 至 0%（尚未突破）。
- 分析為日線訊號，過往區間基準均排除今日；60日均線包含當日收盤。

## 重要限制

- 使用 Yahoo Finance 的 `yfinance`，免費且**不保證可用性、準確性或即時性**。調整後價格 `auto_adjust=True` 有利處理歷史除權息，但供應商可能更新資料或調整方法；請與正式行情核對。
- 偶發股票無資料會列於錯誤清單。日線可能在盤後仍有延遲；**一定要檢查每檔最後交易日**。
- Streamlit Community Cloud 的執行個體可能休眠；每日排程**不是由 Streamlit 執行**，而由 GitHub Actions 執行。GitHub 排程不保證準點，且可能受平台政策影響。
- 股票清單保存在 repository 中，若為公開 repository 便是公開清單。網站供個人研究，若要多人各自登入且永久儲存私人清單，需要再加 Supabase 等雲端資料庫與登入機制。
- 目前沒有自動下單、勝率保證、停損或即時提醒；也沒有完整策略回測。
